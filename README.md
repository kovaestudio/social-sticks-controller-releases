# Social Sticks Sim Controller — Windows downloads

This repository contains Windows installers and update packages only. Application source is maintained privately.

Download the Setup.exe from [the latest release](https://github.com/kovaestudio/social-sticks-controller-releases/releases/latest). Exit old portable controllers before installing. Install under the Windows account used for the simulator and pair the bay once.

Installed controllers download future releases automatically. They install between 04:00 and 06:00 UK time only when the local bay session is idle, there is no imminent cached booking, and the PC has had no input for ten minutes. The PC must be signed in, running and online to receive updates. Pairing persists across updates.

Initial Windows acceptance testing is in progress. Installers currently are not Authenticode signed.
